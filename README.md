# 🌟 Luminar

A React + TypeScript + Vite property listing app with landing pages, featured properties, and location highlights.

## 🚀 Quick start

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## ✨ Highlights

- ✅ React Router for navigation
- ✅ Axios for API calls
- ✅ Built with Vite and TypeScript
